# МаноБанк

Веб-приложение с пятью финансовыми калькуляторами на Laravel, Blade и SQLite.

Работающий сайт: **https://manobank.2-27-40-156.sslip.io/**.
Временное имя привязано к IP сервера. Административный вход: `/admin/login`.

| Продукт | Ставка | Основные ограничения |
| --- | --- | --- |
| Ипотека | 9,6% годовых | Стоимость недвижимости 100 000–15 000 000 ₽; взнос от 10%; срок 1–30 лет |
| Автокредит | 3,5% годовых | Стоимость автомобиля 100 000–6 000 000 ₽; взнос от 0%; срок 1–7 лет |
| Потребительский кредит | 14,5% годовых | Сумма 100 000–6 000 000 ₽; срок 1–7 лет |
| Пенсионные накопления | 6% годовых | Взнос 3 000–20 000 ₽ в месяц; взносы не более 10 лет; выплаты 240 месяцев |
| Вклад повседневный | 7% годовых | Сумма от 50 000 ₽; один срок: 3, 6, 9 или 12 месяцев |

Все ставки фиксированы. Кредитные продукты используют аннуитетный расчёт;
пенсионные накопления и вклад имеют собственные формулы. Во время пенсионных
взносов проценты не начисляются. По вкладу проценты начисляются ежедневно
без капитализации и выплачиваются в конце срока. Денежные результаты
отображаются в целых рублях; внутренние вычисления сохраняют точность.

## Возможности

- Отдельная форма каждого продукта, проверка введённых данных, расчёт и сброс.
- Формирование полного расчёта в PDF и отправка пользователю через Mail.ru.
- Закрытая административная панель с историей расчётов и выгрузкой выбранных
  записей в XLSX.
- Управление внутренними черновиками калькуляторов без изменения пяти
  публичных продуктов.
- Контакты, реквизиты, изображения входной группы и карты проезда.
- Техническая статистика, резервное копирование и проверка восстановления.

## Структура

```text
site/                          приложение Laravel, конфигурация и тесты
  app/Modules/                 функциональные модули
  resources/                   шаблоны Blade, стили и JavaScript
  database/                    миграции и начальные данные
  public/                      единственный публичный каталог веб-сервера
  tests/                       автоматические проверки
tools/                         сценарий запуска для Windows и настройки PHP
docs/                          руководство по эксплуатации
visualizations/manobank/       два изображения, используемые страницей контактов
```

Модули: `Site`, `Catalog`, `Loans`, `Pension`, `Deposit`, `Calculations`,
`Reports`, `Mail`, `Administration`, `Monitoring`, `Maintenance`.
Формулы принадлежат расчётным модулям, сохранённые результаты — `Calculations`,
PDF и XLSX — `Reports`, доставка писем — `Mail`, административный доступ —
`Administration`. Отдельного `Core` нет.

## Требования к среде

- PHP 8.5, 64 бита. Текущий `composer.lock` требует PHP не ниже 8.4.1;
  PHP 8.3 для этого набора зависимостей недостаточно.
- Composer 2.
- Node.js 22.12 или новее и npm для сборки интерфейса.
- Расширения PHP: PDO SQLite, ctype, DOM, fileinfo, filter, GD, hash, iconv,
  JSON, libxml, mbstring, OpenSSL, PCRE, session, SimpleXML, tokenizer, XML,
  XMLReader, XMLWriter, ZIP и zlib. GMP рекомендуется для ускорения расчётов.

Установленные зависимости и исполняемые файлы инструментов в репозиторий
не входят. Их версии определяются `site/composer.lock` и `site/package-lock.json`.
Не заменяйте `install` на `update` при восстановлении проекта.

## Первый запуск в Windows

Команды выполняются из корня репозитория. PHP, Composer и Node.js должны быть
установлены и доступны в `PATH`. Сценарий `tools/project.ps1` подключает GD и GMP
из установленного PHP; эти расширения должны присутствовать в его поставке.

Создайте конфигурацию и пустую базу только при их отсутствии:

```powershell
if (-not (Test-Path -LiteralPath 'site/.env')) {
    Copy-Item -LiteralPath 'site/.env.example' -Destination 'site/.env'
}
if (-not (Test-Path -LiteralPath 'site/database/database.sqlite')) {
    New-Item -ItemType File -Path 'site/database/database.sqlite' | Out-Null
}
& .\tools\project.ps1 composer install
```

Только для нового файла `.env` с пустым `APP_KEY` создайте ключ:

```powershell
& .\tools\project.ps1 php artisan key:generate
```

Подготовьте таблицы, пять публичных продуктов и интерфейс:

```powershell
& .\tools\project.ps1 php artisan migrate --seed
& .\tools\project.ps1 npm ci
& .\tools\project.ps1 npm run build
& .\tools\project.ps1 php artisan manobank:admin-password
& .\tools\project.ps1 composer serve
```

Адрес сайта: <http://127.0.0.1:8000/>. Остановка — `Ctrl+C`.
Встроенный сервер PHP используется для локальной проверки.
Если PowerShell запрещает запуск сценариев, каждую команду можно выполнить
через `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\project.ps1`
с теми же аргументами; постоянная политика системы не изменяется.

## Первый запуск в Linux

После установки перечисленных инструментов и расширений выполните из корня
репозитория:

```bash
cd site
test -f .env || cp .env.example .env
test -f database/database.sqlite || touch database/database.sqlite
composer install
```

Только для новой конфигурации с пустым `APP_KEY`:

```bash
php artisan key:generate
```

Затем:

```bash
php artisan migrate --seed
npm ci
npm run build
php artisan manobank:admin-password
composer serve
```

Команды `composer serve` и последующие команды этого раздела выполняются
из `site/`. Существующий ключ и рабочую базу при повторном запуске сохраняют.

## Административная панель

Адрес: `/admin/login`. Вход также доступен по ссылке «Вход для администратора»
в подвале сайта.

Email администратора: `supp.manobank@mail.ru`. Готового пароля в исходниках нет:
он задаётся локально командой `php artisan manobank:admin-password`.
Минимальная длина — 12 символов; ввод скрыт и требует повторения.
Пароль приложения и пароль почтового ящика задаются отдельно.

Для выгрузки отметьте нужные расчёты галочками и нажмите «Выгрузить XLSX».
Без выбора кнопка неактивна. В файле будут только отмеченные записи и их графики.

## Отправка расчёта на Email

Приложение автоматически отправляет короткое письмо с PDF-вложением,
без копии администратору. Используется транспорт `mailru`:
`smtp.mail.ru`, порт `465`, SMTPS, отправитель `supp.manobank@mail.ru`.

В собственной конфигурации `site/.env` необходимо задать `MAIL_PASSWORD`
паролем внешнего приложения Mail.ru и включить `MANOBANK_MAIL_ENABLED=true`.
После изменения выполните `php artisan config:clear` из `site/`
либо ту же команду через `tools/project.ps1` в Windows.

В `.env.example` отправка отключена, пароль отсутствует.
Для запуска калькуляторов и тестов SMTP-доступ не требуется.
На новом сервере отдельно проверяются доступность SMTP, принятие письма
и фактическое получение PDF. Наличие исходников не подтверждает доставку.

## Проверки

Из `site/` при установленных зависимостях:

```bash
composer test
npm run build
```

В Windows из корня репозитория:

```powershell
& .\tools\project.ps1 composer test
& .\tools\project.ps1 npm run build
```

Автоматические проверки используют отдельную SQLite в памяти;
настоящие письма во время тестов не отправляются.

## Размещение

Работающему серверу нужен корень веб-сервера `site/public`.
В конфигурации задаются фактический `APP_URL`, `APP_ENV=production`,
`APP_DEBUG=false`, HTTPS и `SESSION_SECURE_COOKIE=true`.
Процесс PHP должен иметь необходимые права на `storage`, `bootstrap/cache`,
файл SQLite и содержащий его каталог. Папку `visualizations/manobank`
нужно сохранить рядом с `site`: приложение использует её для изображений.

Подробные процедуры сопровождения и восстановления:
[руководство по эксплуатации](docs/Эксплуатация_МаноБанк.md).

## Состав исходников

В комплект не включены `.env`, рабочая SQLite, пароли, сессии, журналы,
резервные копии, установщики и установленные зависимости. Ресурсы интерфейса
собираются из исходников командой `npm run build`.

Файл `publication-manifest.json` содержит SHA-256 каждого файла комплекта
на момент подготовки. После дальнейших изменений исходников эти контрольные
суммы нужно пересоздать либо удалить устаревший манифест.

Laravel и сторонние библиотеки сохраняют собственные лицензии,
поставляемые вместе с соответствующими пакетами зависимостей.
